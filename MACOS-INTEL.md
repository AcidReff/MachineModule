# Intel Mac build instructions

The current build script now produces **Universal (Intel + Apple Silicon)** app
and VST3 bundles. Use [MACOS-UNIVERSAL.md](MACOS-UNIVERSAL.md) for setup, building,
output paths and testing. You can compile the Universal build on your Intel Mac.

The earlier Intel-only build script/source and Windows binaries are preserved in
`../MachineModule-backups/0.4.4-before-macos-universal`.
